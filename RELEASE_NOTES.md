Ein kleines Update: NeuroSim lässt sich jetzt freiwillig unterstützen.

## Neu
- **NeuroSim unterstützen:** Im Info-Dialog (F1) gibt es die Schaltfläche »NeuroSim unterstützen« (Ko-fi, freiwillig), in der Fußzeile der Startseite einen kleinen Link »Unterstützen«. Beide öffnen nur die Ko-fi-Seite im Browser; NeuroSim selbst überträgt dabei nichts. NeuroSim bleibt kostenlos und voll nutzbar.

## Installation
`NeuroSim.exe` herunterladen und starten. Keine Installation nötig, läuft auf Windows 10 und 11 (64 Bit). Wer eine ältere Version benutzt, kann im Info-Dialog (F1) über „Jetzt nach Updates suchen“ aktualisieren.

Die EXE ist nicht signiert. Zeigt Windows „Der Computer wurde durch Windows geschützt“, über **Weitere Informationen → Trotzdem ausführen** starten.

## Hinweis
NeuroSim dient ausschließlich der Aus-, Fort- und Weiterbildung. Die Kurven sind simuliert. NeuroSim ist kein Medizinprodukt. Lizenz: GPL-3.0-or-later.
